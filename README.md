### Средняя №2. Чётные числа

- `get_even(numbers)` — `filter` с лямбдой `lambda n: n % 2 == 0`, возвращает список;
- `iter_even(numbers)` — генераторное выражение: числа выдаются по одному, список целиком не создаётся. В `main.py` из генератора берутся только первые два значения через `itertools.islice`.

### Средняя №4. Факториал через `reduce`

`reduce(operator.mul, range(1, n + 1), 1)`. Начальное значение `1` нужно, чтобы `0! = 1`: при `n = 0` диапазон пустой. Для отрицательных и нецелых `n` выбрасывается `ValueError`. `factorial_table(k)` строит таблицу `0!..k!` через `map`. В тестах результат сверяется с `math.factorial`.

### Средняя №7. Декоратор `@log_calls`

Пишет в журнал через стандартный модуль `logging` (логгер `lab4`):

- перед вызовом — имя функции и аргументы, в том числе именованные: `вызов divide(6, b=3)`;
- после вызова — результат: `divide(6, b=3) вернула 2.0`;
- при исключении — сообщение уровня `ERROR`, после чего исключение пробрасывается дальше.

За счёт `logging`, а не `print`, вывод можно направить в файл или отключить настройкой, не меняя декоратор. В тестах журнал проверяется через `assertLogs`.

### Повышенная №2. Мемоизация `@memoize`

Результаты хранятся в словаре, ключ — `(args, отсортированные kwargs)`, поэтому `f(a=1, b=2)` и `f(b=2, a=1)` попадают в одну ячейку кэша. У обёртки есть `cache_info()` (попадания, промахи, размер) и `cache_clear()`. Пример — рекурсивный `fibonacci`: без кэша `fibonacci(100)` считался бы практически бесконечно, а с кэшем каждое значение 0..100 вычисляется ровно один раз (тест проверяет, что промахов ровно 101).

### Повышенная №6. Декоратор с параметрами `@retry`

```python
@retry(attempts=3, exceptions=(ConnectionError,), delay=0.5)
def request(): ...
```

Три уровня вложенности: `retry(параметры)` возвращает `decorator(func)`, а тот возвращает `wrapper(*args, **kwargs)`. Функция вызывается повторно, если выбросила исключение из списка `exceptions`, но не больше `attempts` раз; последнее исключение пробрасывается. Другие исключения не перехватываются. Между попытками делается пауза `delay`, в тестах `time.sleep` подменяется через `unittest.mock`. Счётчик неудачных попыток хранится в `wrapper.failures`.
